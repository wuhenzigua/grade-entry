# 成绩快录 · Grade Entry

一个在浏览器本地处理 Excel 的成绩登记助手：**输入学号尾号 → 默认 A → 回车保存 → 继续下一份作业**。

无需后端、账号或构建工具。学生名单和成绩保存在当前浏览器，不上传到服务器。

## 快速开始

下载仓库 ZIP 并解压，用浏览器打开 `index.html`，导入自己的 `.xlsx` 登记表即可。建议使用 Chrome 或 Edge，并允许浏览器本地存储。

也可以使用 Python 启动本地服务器：

```sh
git clone https://github.com/wuhenzigua/grade-entry.git
cd grade-entry
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000>。采用本地服务器时，应始终使用相同地址和端口以恢复进度。

## 登记流程

1. 点击 **导入 Excel**，选择登记表。
2. 确认日期，例如 `927` 表示 9 月 27 日，`1008` 表示 10 月 8 日。
3. 输入学号尾号或姓名，核对匹配学生。
4. 唯一匹配且没有已有成绩时默认 A，按 **Enter** 保存；需要 B 或 C 时，先按对应字母，再按 Enter。
5. 保存后搜索框自动清空并保持焦点，继续输入下一份作业的尾号。
6. 点击 **导出成绩表** 下载更新后的 Excel，原始文件不会被覆盖。

尾号重复时，使用上下方向键选择，按 Enter 确认学生，再按 Enter 保存。已有成绩会作为当前值显示，保存时覆盖。也支持缺交、请假、Esc 清空、撤销上一条和未录入筛选。

## 支持的登记表布局

当前版本针对以下固定布局，**不是任意 Excel 的通用导入器**：

| 列  | 内容                                    |
| --- | --------------------------------------- |
| A   | 序号                                    |
| B   | 学号（至少 6 位纯数字，建议存储为文本） |
| C   | 姓名                                    |
| D   | 班级                                    |
| E–P | 最多 12 次日期及对应成绩                |
| Q   | 总评（保留原值，不自动计算）            |

- 表头行 B、C 列分别是“学号”“姓名”，紧接着的下一行是日期行。
- 日期使用月日编码，例如 `915`、`927`、`1008`，当前版本不按年份区分，也不支持 Excel 日期序列号。
- 支持同一工作簿内多工作表、多段重复表头；所有识别到的学生共同显示，学号必须全局唯一。
- 每位学生按所属表头段的日期定位成绩列，不假定不同页的日期列一致。
- 新日期使用该段内表头和学生成绩均为空的列；无日期但已有成绩的列会跳过。
- 日期栏已满时拒绝写入，须先在原表中整理。
- 支持未加密 `.xlsx`，不支持 `.xls`、加密文件、成绩公式编辑或合并成绩单元格。

## 数据保存与导出

通过 IndexedDB 保存原始文件、修改记录和当前日期。当前浏览器仅保存一份活动登记表，重新导入会替换当前进度。换浏览器、设备、网址、端口，或清理网站数据后，不能依赖原有缓存恢复，因此每次登记结束都应导出备份。

导出使用 JSZip 读取原始 XLSX，只替换修改过的成绩单元格和必要的日期表头，保留其余工作簿内容。页面不包含学生示例数据、遥测、外部字体或 CDN 请求。

## 静态部署

将 `index.html`、`style.css`、`app.js`、`jszip.min.js` 放在同一个静态网站目录即可，无需安装依赖。

GitHub Pages：在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支 `main`、目录 `/ (root)`，保存后等待发布。网站代码可以公开，用户导入的数据仍留在各自浏览器。

## 源码结构

```text
index.html           界面结构
style.css            响应式样式
app.js               名单解析、键盘操作、保存及 XLSX 修改
jszip.min.js         JSZip 3.10.1 浏览器包
licenses/            第三方许可证
THIRD_PARTY_NOTICES.md 第三方组件说明
```

JavaScript 语法检查：

```sh
node --check app.js
```

修改后建议验证：唯一/重复尾号、A/B 连续录入、已有成绩覆盖、撤销、刷新恢复、日期栏分配、导出再导入，以及原表合并单元格和样式是否保持。不要将真实学生文件或含姓名学号的截图提交到仓库。
